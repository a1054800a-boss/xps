# 🔨 Building XSpoof APK\n\n## Prerequisites\n\n- **Android Studio** (latest version recommended)\n- **JDK 11+** installed\n- **Android SDK** (API 33+)\n- **Gradle** (included with Android Studio)\n- **Git** (for cloning)\n\n## Build Options\n\n### Option 1: Build via Android Studio (Easiest)\n\n1. **Clone Repository**\n   ```bash\n   git clone https://github.com/carlahenrikssen-web/XSpoof.git\n   cd XSpoof\n   ```\n\n2. **Open in Android Studio**\n   - File → Open → Select XSpoof folder\n   - Wait for Gradle sync to complete\n\n3. **Build APK**\n   - **Debug APK**: Build → Build Bundle(s) / APK(s) → Build APK(s)\n   - **Release APK**: Build → Generate Signed Bundle / APK\n     - Create keystore or use existing\n     - Select \"APK\" option\n     - Choose \"release\" build variant\n\n4. **Find APK**\n   - Debug: `app/build/outputs/apk/debug/app-debug.apk`\n   - Release: `app/build/outputs/apk/release/app-release.apk`\n\n### Option 2: Build via Command Line\n\n1. **Clone Repository**\n   ```bash\n   git clone https://github.com/carlahenrikssen-web/XSpoof.git\n   cd XSpoof\n   ```\n\n2. **Build Debug APK**\n   ```bash\n   ./gradlew assembleDebug\n   ```\n   Output: `app/build/outputs/apk/debug/app-debug.apk`\n\n3. **Build Release APK (Unsigned)**\n   ```bash\n   ./gradlew assembleRelease\n   ```\n   Output: `app/build/outputs/apk/release/app-release.apk`\n\n4. **Build & Sign Release APK**\n   ```bash\n   # First, create a keystore (one-time)\n   keytool -genkey -v -keystore xspoof.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias xspoof\n   \n   # Then build with signing\n   ./gradlew assembleRelease \\\n     -Pandroid.injected.signing.store.file=./xspoof.keystore \\\n     -Pandroid.injected.signing.store.password=YOUR_PASSWORD \\\n     -Pandroid.injected.signing.key.alias=xspoof \\\n     -Pandroid.injected.signing.key.password=YOUR_PASSWORD\n   ```\n\n### Option 3: Docker Build (No Local Setup)\n\n1. **Create Dockerfile**\n   ```dockerfile\n   FROM ubuntu:22.04\n   \n   RUN apt-get update && apt-get install -y \\\n       openjdk-11-jdk \\\n       wget \\\n       unzip \\\n       git\n   \n   # Install Android SDK\n   RUN mkdir -p /android-sdk\n   ENV ANDROID_HOME=/android-sdk\n   ENV PATH=$ANDROID_HOME/tools:$ANDROID_HOME/tools/bin:$ANDROID_HOME/platform-tools:$PATH\n   \n   RUN wget -q https://dl.google.com/android/repository/sdk-tools-linux-4333796.zip -O /tmp/sdk.zip && \\\n       unzip -q /tmp/sdk.zip -d $ANDROID_HOME && \\\n       rm /tmp/sdk.zip\n   \n   RUN yes | sdkmanager --licenses\n   RUN sdkmanager \"platform-tools\" \"platforms;android-33\" \"build-tools;33.0.0\"\n   \n   WORKDIR /workspace\n   \n   CMD [\"/bin/bash\"]\n   ```\n\n2. **Build & Run**\n   ```bash\n   docker build -t xspoof-builder .\n   docker run -it -v $(pwd):/workspace xspoof-builder\n   \n   # Inside container\n   cd /workspace\n   git clone https://github.com/carlahenrikssen-web/XSpoof.git\n   cd XSpoof\n   ./gradlew assembleDebug\n   ```\n\n## Build Output\n\n### Debug APK\n- **Size**: ~10-15 MB\n- **Signature**: Debug key (automatically generated)\n- **Installation**: Direct installation or adb install\n- **Use Case**: Testing & development\n\n```bash\nadb install app/build/outputs/apk/debug/app-debug.apk\n```\n\n### Release APK\n- **Size**: ~8-12 MB (ProGuard optimized)\n- **Signature**: Your keystore\n- **Installation**: Google Play or direct install\n- **Use Case**: Production deployment\n\n```bash\nadb install app/build/outputs/apk/release/app-release.apk\n```\n\n## Troubleshooting\n\n### Build Fails: \"Gradle sync failed\"\n```bash\n# Clean and rebuild\n./gradlew clean\n./gradlew build\n```\n\n### Build Fails: \"SDK not found\"\n```bash\n# Install missing SDK components\nsdkmanager \"platforms;android-33\" \"build-tools;33.0.0\"\n```\n\n### Build Fails: \"Permission denied on gradlew\"\n```bash\nchmod +x gradlew\n./gradlew assembleDebug\n```\n\n### Build Fails: \"Out of memory\"\n```bash\n# Increase Gradle heap size\nexport GRADLE_OPTS=\"-Xmx4096m\"\n./gradlew assembleDebug\n```\n\n## Installation on Device\n\n### Prerequisites\n- USB debugging enabled\n- Device connected via USB\n- ADB installed\n\n### Install Debug APK\n```bash\nadb install app/build/outputs/apk/debug/app-debug.apk\n```\n\n### Install Release APK\n```bash\nadb install app/build/outputs/apk/release/app-release.apk\n```\n\n### Uninstall\n```bash\nadb uninstall com.example.xspoof\n```\n\n### View Logs\n```bash\nadb logcat | grep XSpoof\n```\n\n## Configuration After Installation\n\n1. **Open XSpoof App**\n   - Configure device properties\n   - Add target apps\n   - Enable the module\n\n2. **Open LSPosed Manager**\n   - Navigate to Modules\n   - Enable \"XSpoof\"\n   - Select target apps\n   - Reboot device\n\n3. **Verify**\n   ```bash\n   adb logcat | grep XSpoof\n   # Should show: \"XSpoof: Hooking com.example.app\"\n   ```\n\n## CI/CD Automation\n\n### GitHub Actions Setup\n\nCreate `.github/workflows/build.yml`:\n\n```yaml\nname: Build APK\non:\n  push:\n    branches: [main]\n  pull_request:\n    branches: [main]\n\njobs:\n  build:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: actions/setup-java@v3\n        with:\n          java-version: '11'\n      - run: chmod +x gradlew\n      - run: ./gradlew assembleDebug assembleRelease\n      - uses: actions/upload-artifact@v3\n        with:\n          name: apks\n          path: app/build/outputs/apk/**/*.apk\n```\n\n## Advanced: Building Variants\n\n### Build Specific Variant\n```bash\n./gradlew assembleDebug      # Debug version\n./gradlew assembleRelease    # Release version\n./gradlew build              # All variants\n```\n\n### Custom Build Properties\n```bash\n./gradlew assembleRelease \\\n  -PcustomVersion=1.1.0 \\\n  -PcustomName=\"XSpoof Premium\"\n```\n\n## Size Optimization\n\nEnable ProGuard for smaller APK:\n\n```gradle\n// In build.gradle\nrelease {\n    minifyEnabled true\n    proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'\n}\n```\n\n**Result**: ~30% size reduction\n\n## Signing APK\n\n### One-time Keystore Creation\n```bash\nkeytool -genkey -v -keystore xspoof.keystore \\\n  -keyalg RSA -keysize 2048 -validity 10000 \\\n  -alias xspoof\n```\n\n### Sign Existing APK\n```bash\njarsigner -verbose -sigalg SHA1withRSA \\\n  -digestalg SHA1 \\\n  -keystore xspoof.keystore \\\n  app/build/outputs/apk/release/app-release.apk \\\n  xspoof\n```\n\n## Security Notes\n\n- **Keep keystore safe**: Don't commit to git\n- **Use environment variables** for passwords\n- **Enable ProGuard** for release builds\n- **Test thoroughly** before distribution\n\n## Next Steps\n\n1.
