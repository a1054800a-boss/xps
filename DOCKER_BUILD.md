# 🐳 Docker Build Guide\n\n## Why Docker?\n\n- ✅ No need to install Android SDK, JDK, or Gradle locally\n- ✅ Consistent build environment across all systems\n- ✅ Works on Windows, Mac, and Linux\n- ✅ No dependency conflicts\n- ✅ One-time setup, reusable for all future builds\n\n---\n\n## Prerequisites\n\n- **Docker** installed ([Get Docker](https://docs.docker.com/get-docker/))\n- **Docker Compose** installed (usually comes with Docker Desktop)\n- ~2GB disk space\n- Internet connection (for first build)\n\n---\n\n## Quick Docker Build\n\n### Using Docker Compose (Easiest)\n\n```bash\n# Clone repository\ngit clone https://github.com/carlahenrikssen-web/XSpoof.git\ncd XSpoof\n\n# Start build container\ndocker-compose up -d\n\n# Enter container\ndocker-compose exec xspoof-builder bash\n\n# Build APK\n./gradlew assembleDebug\n\n# Exit container\nexit\n```\n\n### Your APK is ready at:\n```\napp/build/outputs/apk/debug/app-debug.apk\n```\n\n---\n\n## Using Docker Directly\n\n### Build the Image\n\n```bash\ngit clone https://github.com/carlahenrikssen-web/XSpoof.git\ncd XSpoof\n\ndocker build -t xspoof-builder:latest .\n```\n\n### Run the Build\n\n```bash\ndocker run -it -v $(pwd):/workspace xspoof-builder:latest /bin/bash\n\n# Inside container:\ncd /workspace\n./gradlew assembleDebug\n\n# APK is now in: app/build/outputs/apk/debug/\nexit\n```\n\n---\n\n## Commands Reference\n\n### Start/Stop Container\n\n```bash\n# Start container\ndocker-compose up -d\n\n# Stop container\ndocker-compose down\n\n# View logs\ndocker-compose logs -f xspoof-builder\n```\n\n### Build Variants\n\n```bash\n# Inside container\n\n# Debug APK\n./gradlew assembleDebug\n\n# Release APK (unsigned)\n./gradlew assembleRelease\n\n# Both\n./gradlew build\n\n# Clean\n./gradlew clean\n```\n\n### One-Line Build\n\n```bash\n# Build without interactive mode\ndocker-compose run xspoof-builder ./gradlew assembleDebug\n```\n\n---\n\n## Troubleshooting\n\n### Docker Build Fails\n\n```bash\n# Rebuild from scratch\ndocker-compose build --no-cache\n```\n\n### Out of Disk Space\n\n```bash\n# Clean up Docker\ndocker system prune -a\n\n# Check space\ndocker system df\n```\n\n### Permission Denied\n\n```bash\n# On Linux, add user to docker group\nsudo usermod -aG docker $USER\n\n# Restart Docker service\nsudo systemctl restart docker\n```\n\n### Cannot Connect to Docker Daemon\n\n```bash\n# Start Docker Desktop or daemon\n# Windows/Mac: Open Docker Desktop\n# Linux: sudo systemctl start docker\n```\n\n---\n\n## Advanced Docker Usage\n\n### Custom Docker Image\n\nEdit `Dockerfile` to add custom tools:\n\n```dockerfile\n# Add to Dockerfile\nRUN apt-get install -y your-package\n```\n\nRebuild:\n```bash\ndocker-compose build --no-cache\n```\n\n### Map Port (for development)\n\n```yaml\n# In docker-compose.yml\nservices:\n  xspoof-builder:\n    ports:\n      - \"8080:8080\"\n```\n\n### Run Multiple Builds\n\n```bash\n# Terminal 1\ndocker-compose run xspoof-builder ./gradlew assembleDebug\n\n# Terminal 2 (same time)\ndocker-compose run xspoof-builder ./gradlew assembleRelease\n```\n\n---\n\n## Docker Image Details\n\n### Base Image\n- Ubuntu 22.04\n\n### Installed Tools\n- OpenJDK 11\n- Android SDK Command-line Tools\n- Platform Tools\n- Build Tools 33.0.0\n- Gradle (from project)\n\n### Image Size\n- ~1.5 GB (first build)\n- Subsequent builds use cache\n\n---\n\n## CI/CD Integration\n\n### GitHub Actions with Docker\n\n```yaml\nname: Build with Docker\n\non: [push]\n\njobs:\n  build:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: docker/setup-buildx-action@v2\n      - uses: docker/build-push-action@v4\n        with:\n          context: .\n          push: false\n      - run: docker-compose run xspoof-builder ./gradlew assembleDebug\n      - uses: actions/upload-artifact@v3\n        with:\n          name: apk\n          path: app/build/outputs/apk/debug/\n```\n\n---\n\n## Comparison: Docker vs Local\n\n| Feature | Docker | Local |\n|---------|--------|-------|\n| Setup Time | 5 min | 15+ min |\n| Dependencies | None needed | SDK, JDK, Gradle |\n| Consistency | High | Varies |\n| Speed | Fast* | Fastest |\n| Space | ~1.5 GB | ~3+ GB |\n| Learning Curve | Low | Medium |\n\n*After first build, subsequent builds are nearly identical in speed\n\n---\n\n## Next
