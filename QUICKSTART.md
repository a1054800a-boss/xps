# 🚀 Quick Start Guide - XSpoof APK Building & Installation\n\n## ⚡ Build APK in 30 Seconds\n\n### For Windows Users:\n```batch\ngit clone https://github.com/carlahenrikssen-web/XSpoof.git\ncd XSpoof\nbuild.bat\n# Select option 1 for Debug APK\n```\n\n### For Linux/Mac Users:\n```bash\ngit clone https://github.com/carlahenrikssen-web/XSpoof.git\ncd XSpoof\nchmod +x build.sh\n./build.sh\n# Select option 1 for Debug APK\n```\n\n### For Command Line (All Platforms):\n```bash\ngit clone https://github.com/carlahenrikssen-web/XSpoof.git\ncd XSpoof\n\n# Linux/Mac:\n./gradlew assembleDebug\n\n# Windows:\ngradlew.bat assembleDebug\n```\n\n---\n\n## 📍 Find Your APK\n\nAfter building, your APK is located at:\n```\napp/build/outputs/apk/debug/app-debug.apk\n```\n\n**Size**: ~12-15 MB\n\n---\n\n## 📱 Install on Android Device\n\n### Prerequisites:\n- USB debugging enabled on device\n- Device connected to computer via USB\n- ADB installed (comes with Android Studio)\n\n### Installation Methods:\n\n#### Method 1: Via ADB (Fastest)\n```bash\nadb install app/build/outputs/apk/debug/app-debug.apk\n```\n\n#### Method 2: Manual Transfer\n1. Copy `app-debug.apk` to device storage\n2. Use file manager to open it\n3. Tap \"Install\"\n4. Grant permissions\n\n#### Method 3: Android Studio\n1. Run → Run app\n2. Select device\n3. App installs automatically\n\n---\n\n## 🎛️ Configure XSpoof\n\n### Step 1: Open XSpoof App\n- Find \"XSpoof\" in your app drawer\n- Tap to open configuration UI\n\n### Step 2: Configure Device Properties\n**General Tab:**\n- ✅ Enable the module\n- Choose: Spoof all apps OR select specific apps\n\n**Device Info Tab:**\n- Set fake Manufacturer (e.g., \"Google\")\n- Set fake Model (e.g., \"Pixel 6\")\n- Set fake Fingerprint\n- Set fake Android ID\n- Set other properties (Brand, Device, Product, Hardware)\n\n**Network Tab:**\n- Set fake IPv4 (e.g., \"192.0.2.123\")\n- Set fake IPv6 (e.g., \"2001:db8::1\")\n\n**Target Apps Tab:**\n- Add specific apps to spoof (if not using \"Spoof All\")\n- Remove apps you don't want to spoof\n\n### Step 3: Open LSPosed Manager\n- Find \"LSPosed Manager\" app\n- Go to Modules\n- Find \"XSpoof\"\n- ✅ Enable it\n- Select target apps\n- Confirm\n\n### Step 4: Reboot Device\n```bash\nadb reboot\n```\nOR manually restart device in Settings\n\n---\n\n## ✅ Verify It's Working\n\n### Check Logs\n```bash\nadb logcat | grep XSpoof\n```\n\nYou should see:\n```\nXSpoof: Hooking com.example.app\nXSpoof: Build fields spoofed\nXSpoof: IPv4 spoofing enabled (192.0.2.123)\nXSpoof: Android ID spoofing enabled\n```\n\n### Test in App\n1. Open your target app\n2. Check device info (Settings, About Phone, etc.)\n3. Should show spoofed values\n\n---\n\n## 🔧 Troubleshooting\n\n### APK Won't Install\n```bash\n# Uninstall first\nadb uninstall com.example.xspoof\n\n# Then install\nadb install app/build/outputs/apk/debug/app-debug.apk\n```\n\n### Module Not Working\n1. Verify LSPosed is enabled\n2. Check XSpoof is enabled in LSPosed Manager\n3. Reboot device\n4. Check logs: `adb logcat | grep XSpoof`\n\n### Build Fails\n```bash\n# Clean and rebuild\n./gradlew clean\n./gradlew assembleDebug\n```\n\n### Permission Denied\n```bash\n# Make sure gradlew is executable (Linux/Mac)\nchmod +x gradlew\n./gradlew assembleDebug\n```\n\n---\n\n## 📊 Pre-built Config Examples\n\n### Spoof as Google Pixel 6:\n```json\n{\n  \"manufacturer\": \"Google\",\n  \"model\": \"Pixel 6\",\n  \"brand\": \"google\",\n  \"device\": \"oriole\",\n  \"product\": \"oriole\",\n  \"fingerprint\": \"google/oriole/oriole:12/S2B2.220816.016:user/release-keys\",\n  \"android_id\": \"a1b2c3d4e5f6g7h8\",\n  \"ipv4\": \"192.0.2.123\",\n  \"ipv6\": \"2001:db8::1\"\n}\n```\n\n### Spoof as Samsung Galaxy S21:\n```json\n{\n  \"manufacturer\": \"Samsung\",\n  \"model\": \"SM-G991B\",\n  \"brand\": \"samsung\",\n  \"device\": \"o1s\",\n  \"product\": \"o1s\",\n  \"fingerprint\": \"samsung/o1s/o1s:12/S901BXXS1AUG1:user/release-keys\",\n  \"android_id\": \"z9y8x7w6v5u4t3s2\",\n  \"ipv4\": \"10.0.0.50\",\n  \"ipv6\": \"fe80::1\"\n}\n```\n\n---\n\n## 🎯 Next Steps\n\n1. ✅ Build APK using one of the methods above\n2. ✅ Install on device\n3. ✅ Configure in XSpoof app\n4. ✅ Enable in LSPosed\n5. ✅ Reboot\n6. ✅ Verify with logs\n\n---\n\n## 📚 Full Documentation\n\nFor detailed information, see:\n- [README.md](README.md) - Project overview\n- [BUILD_GUIDE.md](BUILD_GUIDE.md) - Detailed build instructions\n- [Android Developer Docs](https://developer.android.com/) - Android development reference\n\n---\n\n## ⚠️ Important Notes\n\n- 🔄 Device reboot required after enabling module\n- 📝 Changes to config take effect after reboot\n- 🎯 Some apps may detect spoofing via native code\n- 🔒 Keep your device secure while using this module\n- ⚖️ Use responsibly and legally only\n\n---\n\n**Questions?** Check the troubleshooting section or GitHub Issues.\n\n**Made with ❤️ for Android developers**\n"
